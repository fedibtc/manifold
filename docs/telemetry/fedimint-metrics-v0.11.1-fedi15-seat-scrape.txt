# Complete Prometheus response captured from a running fedi15 fedimintd guardian
# seat supervised by an FMan. It remains an actual legacy regression fixture for
# the parser and allowlist when bound to its own fedi15 marker. Its old release
# marker is intentional; it makes no production cross-release compatibility claim.
#
# Why this file exists. The policy is already checked against
# `fedimint-metrics-v0.11.1-fedi17.tsv`, which enumerates what the pinned source
# *registers*. That is a source-level check: it cannot show what a running
# producer actually *emits* -- which families are present, which label values
# occur, which buckets are filled -- so the inventory can be self-consistent and
# still disagree with the producer it was written for. `tests/metrics_policy.rs`
# replays this response through the shipped policy to close that gap.
#
# Captured 2026-08-21 from the Fedi manifold-staging fleet on Mutinynet. The
# contents are aggregate counters, timings, and bounded operational labels only:
# no keys, invite codes, addresses, hostnames, or transaction identifiers. Every
# `#` line is skipped by the policy parser, so this header is inert.
#
# Capture a fedi16 producer before treating this fixture as evidence for the new
# v2 families; this retained capture only verifies the supported old-producer subset.
