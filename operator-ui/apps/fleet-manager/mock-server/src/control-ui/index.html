Scenarios

Swap the whole mock world for a named snapshot. Loading one also clears the session, so the app returns to the sign-in prompt.

Quick patches

Tweak one field of the current state without a full scenario swap.

authMode password serves POST /api/auth and requires a session cookie. trusted_proxy mounts no auth route at all (404) and lets every admin call through, mirroring the real daemon's two deployment modes. Affects: boot gate / sign-in
latencyMs Artificial delay added before every admin response. Use it to check loading and skeleton states. Affects: app-wide (loading states)
field path Set any single field by dotted path, e.g. seats.0.report.health = "unavailable", or paymentFederations.0.receivable = false. The value is parsed as JSON, so quote strings. Affects: whichever screen reads that field

Error injection

Force one admin verb to return { "Err": message }, so you can test the screen that calls it. Persists until cleared or reset.

method The AdminRequest variant to fail, e.g. ListSeats (Seats), SeatStatus (Seat detail), ListPaymentFederations (Wallet), ShowPlans (Plans), Onboarding (boot gate — fails every screen). Affects: whichever screen calls this verb
message The error string the verb should return. Leave blank to clear the forced error for that verb. Affects: response for the verb above only

Lifecycle

Reset Restores the default fresh-fleet scenario, clears all forced errors, and clears the session. Affects: every screen

Raw MockState

There is no GET-state endpoint; Refresh issues a no-op POST /__control/patch {}, which returns the current state unchanged.
