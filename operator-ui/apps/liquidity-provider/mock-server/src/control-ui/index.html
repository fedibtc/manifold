Scenarios

Quick patches

Tweak one field of the current state without a full scenario swap.

phase Daemon rollout phase (9 / 10 / 11). Gates whichever methods are listed in DEFERRED_PHASE (empty today — no method is currently phase-gated). Affects: app-wide (route availability)
bootMode normal boots straight through; restore replays the boot-gate's restore-in-progress path. Affects: boot gate (first load of every screen)
latencyMs Artificial delay added before every admin response. Use it to check loading/skeleton states. Affects: app-wide (loading states)

Error injection

Force one admin method to fail with a service-error code, so you can test the screen(s) that call it. Persists until cleared or reset.

method The admin RPC method name to fail, e.g. get_funds (Funds), create_deposit_address (Funds → Top up), list_liquidity_requests (Requests), list_allocations (Allocations). Pick from the list or type any of the 15 routed methods. Affects: whichever screen calls this method
code The service-error code the method should return. (clear) removes the forced error for this method. Affects: response for the method above only

Lifecycle

Tick Runs the mock's deterministic republish step (advertisement flips to published if it's ready). Affects: Advertisement
Reset Restores the default setup-fresh scenario and clears all forced errors. Affects: every screen
