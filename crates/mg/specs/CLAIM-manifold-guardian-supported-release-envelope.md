# CLAIM-manifold-guardian-supported-release-envelope: Manifold Guardian releases have a supported envelope

The release pins `fedimintd`, states workload limits, dependency-availability
preconditions, operation deadlines, and a recovery objective, and identifies
every supported FA or Admin operation and transition. A formed seat is not
upgraded to a different version unless that transition is explicitly supported.

## Assumptions

- The release pins `fedimintd`.
- The release states workload limits, dependency-availability preconditions,
  operation deadlines, and a recovery objective.
- The release identifies every supported FA or Admin operation and transition.
- A formed seat is not upgraded to a different version unless that transition is
  explicitly supported.
